GitHub 上的 fast-anything 项目提出一种性能优化思路：不要为了提速把整个应用改写成 Rust，而应先对 Python、Node 或 Ruby 应用做性能分析，找出最慢的 5% 代码。随后用编码代理移植这些热点函数，并验证移植前后行为一致。项目强调只改热点、保留其余代码，以降低重写成本和风险。其看点在于把性能优化限定在可验证的小范围，而不是全量重写。（Rust · 共 4,045 star，日均新增 871） 标签：agent-skills, ai-agents, claude-code, claude-code-plugin, codex, developer-tools, ffi, mcp, mcp-server, napi-rs, nodejs, optimization, performance, profiler, pyo3, python, rewrite-it-in-rust, ruby, rust, typescript
