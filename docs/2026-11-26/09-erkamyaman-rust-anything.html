GitHub 上出现 rust-anything 项目，目标是把整个应用逐步重写为 Rust，而非一次性迁移。它要求每一步都对照原应用记录下来的行为进行校验，以降低重写带来的回归风险。项目覆盖 TypeScript、Python、C、Go、Ruby 和 Java 编写的 CLI、HTTP 服务器与库。这种分步迁移加逐段验证的方式，为多语言存量项目转向 Rust 提供了可参考的思路。（Rust · 共 9,708 star，日均新增 996） 标签：agent-skills, claude-code, cli, code-migration, codex, ffi, golang, java, javascript, mcp, migration, napi, performance, porting, pyo3, python, rewrite, ruby, rust, typescript
