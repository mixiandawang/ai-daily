原文标题：Tokendoctor – the same Claude Code for up to 38% less
Hacker News 出现 Tokendoctor，一个在本地运行的 Claude Code 插件，宣称同等使用最高省 38%。作者用六周真实使用测算：主线程每请求按 API 标价，启用 400K 窗口并为子代理使用 Sonnet 后，成本降 38%，每请求上下文从 412K 降至 219K。相同会话按 400K 窗口重放，仅改窗口就使主线程成本降 33%、总支出降 20%。它还提供会话重放、38 项检查优化、旧工具输出替换摘要、撤销和本地仪表盘，安装后可按需应用改动。
